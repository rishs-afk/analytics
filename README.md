# Northstar Client Portal

A clean static client analytics portal built around the existing Looker Studio embed.

## Use

1. Open `index.html` directly in a browser for a local preview.
2. Deploy the folder to any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages, etc.).
3. Replace the placeholder client/account details in `index.html` when using it for a real client.
4. The Looker Studio iframe is already connected to:
   `781a5a37-d71b-44af-beb6-caa2c947a6cf/page/y4c8F`

No frameworks or package installation required.
